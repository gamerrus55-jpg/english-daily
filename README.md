# English Daily

Личное приложение для разговорного английского и понимания на слух.

## Этап 1 · Говорю фразами
- **Курс** — 32 разговорные конструкции × подстановки (≈350 фраз), от простого к сложному.
- **⚡ Вспомни быстро** — фраза по-русски, несколько секунд, чтобы сказать её по-английски.
- **🎧 Аудиоурок** — как Pimsleur: русская фраза → пауза, говоришь сам → правильный ответ → повтор. Можно не смотреть в экран.
- **🧩 Собери фразу** — из перемешанных слов.

## Этап 2 · Понимаю на слух
- **🎬 Диалоги** — 10 жизненных сценок, два голоса, три скорости, текст и перевод по кнопке, пауза для повтора (shadowing).
- **👂 На слух** — услышал, выбрал перевод.
- **✍️ Диктант** — услышал, написал, увидел ошибки.
- **Живая речь** — gonna, wanna, gotta, dunno и другие разговорные фразы.

Повторения интервальные: ошибся — вернётся в конце занятия, вспомнил — через 1, 3, 7, 16, 35 дней.

## Обновления
Каждый push в `main` собирает новый APK. Приложение само сообщает о новой версии.
