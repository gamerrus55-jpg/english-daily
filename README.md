# English Daily

Личное приложение для тренировки английского: быстро вспоминать слова и собирать из них фразы.

## Режимы
- **⚡ Вспомни быстро** — фраза по-русски, 5–8 секунд, чтобы сказать её по-английски.
- **🧩 Собери фразу** — собрать английскую фразу из перемешанных слов.
- **👂 На слух** — услышать фразу и выбрать перевод.
- **📖 Разговорник** — все слова и фразы с озвучкой.

Озвучка — встроенный синтезатор речи Android (офлайн). Повторения — интервальные: ошибся — вернётся скоро, вспомнил — через 1, 3, 7, 16, 35 дней.

## Скачать
Последняя сборка: Releases → `EnglishDaily.apk`.
Каждый push в `main` собирает новый APK автоматически.

## Добавить свои фразы
Файл `app/src/main/java/ru/my/englishdaily/Content.kt` — строки вида `"english" to "русский",`.
